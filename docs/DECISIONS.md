# Architecture decisions

- 2026-11-06: Role-scoped model context includes captured identity evidence for profile and deterministic metrics for financials, so iq3_s can answer without reading the entire snapshot. Validated prior outputs occur once per request; role/tool prompts distinguish optional data reads and request concise findings. This addresses observed redundant reads/token exhaustion without increasing limits or replacing the configured model. Full immutable evidence/calculations remain in the persisted run, and all output validation still runs outside the model.

- 2026-11-06: Live yearly history exposed repeated per-bar provenance overflowing the model context after a six-tool batch (251 history bars alone serialized to 110,318 bytes). The model-only history tool now uses a lossless table with shared metadata and ordered date/close rows; differing source/currency/cache/limitation metadata receives separate entries. API PriceBar responses and captured history remain unchanged, with no truncation, sampling or increase to model budgets. A transport-level regression reproduces the original context failure and reconstructs every bar exactly after the change.

- 2026-11-06: Independent React/Vite + FastAPI implementation; no reference code copied. OpenStock AGPL is conceptual reference only.
- 2026-11-06: Python stdlib SQLite repository keeps persistence lightweight; explicit schema versioning, JSON payloads for immutable research artifacts. Background tasks execute sequential stages with bounded HTTP requests; interrupted runs are marked incomplete at startup.
- 2026-11-06: Fixture mode is explicit and synthetic; it never masquerades as live provider/model output. Live mode requires server environment configuration and never reads other projects' secrets.
- 2026-11-06: Strict live numeric fidelity uses structured claims with exact evidence/calculation value and unit bindings; free-form model narrative cannot include numeric literals. Final numeric tables and source timestamps are rendered by server code. This deliberately conservative contract can require retries from models that insert dates/numbers in prose.
- 2026-11-06: Overall analyses retain incomplete status when material evidence/consensus is missing, even when every stage validates. Risk can trigger one correction sequence; failed reassessment discards stale risk output.
- 2026-11-06: Local research concurrency is one worker and four bounded queued/running jobs. Model calls have bounded iterations, wall time, output allocation and reported total token budgets. Startup marks interrupted runs incomplete instead of pretending completion.
- 2026-11-06: Provider usage is recorded only when returned. Output allocation remains bounded even when usage is absent; serialized context has explicit per-request/per-run byte limits. Malformed protocol and invalid negative usage are rejected safely.
- 2026-11-06: Frontend Testing Library DOM peer is declared explicitly so clean installs retain test exports despite npm10 optional-peer resolution workaround. Non-HTTP synthetic fixture sources display as text instead of broken external links.
- 2026-11-06: Live HTTP responses carry immutable per-call capture metadata. Cached normalized facts retain original network fetched_at and expose cached=true; no stale-on-error fallback. SIC classification is separately evidenced.
- 2026-11-06: TradingView bootstrap script runs in an opaque-origin data-URL iframe. This avoids React cleanup races while compatible sandbox settings allow the nested provider frame its own cookie origin. Parent status messages verify sender window and attempt; data is never read by agents. Browser regression covers network failure/retry.
- 2026-11-06: Optional news summaries are explicit user actions in live mode only. They reuse report schema/client/tool/evidence validation over captured headline text; full articles, numeric interpretation and social sentiment are unavailable. No second orchestrator or fixture AI summaries were introduced.
- 2026-11-06: Support user-configured link-local IPv4 HTTP model endpoints for the local WSL server, alongside loopback HTTP and HTTPS. Embedded credentials/query strings remain rejected. The supplied server rejects structured response_format combined with tools; the shared client retries that exact HTTP 400 once without response_format, remembers the capability for the run, and retains prompts, tool restrictions and external schema/evidence/numeric validation. The retry consumes the existing bounded request loop.
- 2026-11-06: User expanded provider scope to free-first U.S./Canadian research. Canonical Canadian listings use explicit .TO/.V suffixes and CA/CAD contracts throughout existing API/run/storage paths. Canadian-only statements and Finnhub free Canadian quotes remain unavailable until permitted access/coverage is established; no SEDAR+ automation or assumed SEC coverage. No database migration is needed because positions already store currency and runs are JSON snapshots.
- 2026-11-06: Keep existing SEC/Finnhub adapters and add optional history routing: auto tries installed yfinance, then configured Alpha Vantage for U.S. listings. Explicit provider selection remains available; no source mixing or credential requirement for startup. Yahoo history is labeled educational/personal-use, verifies symbol/currency and uses project-local caches. Bounded history operation pacing is distinct from yfinance internal request behavior.
- 2026-11-06: Canadian Valet macro/FX uses the shared transport and existing signals response; FRED stays optional. FX rates are context only, not automatic holdings conversion. Host-specific transport policies and a local Alpha Vantage daily budget preserve original captured timestamps and reject soft API errors before caching.

- 2026-11-06: Real iq3_s probe exposed invented parameters for parameterless captured-data tools. Invalid arguments to declared tools now receive fixed, sanitized model feedback within the existing tool loop; rejected calls never execute. Unknown tools, context size and call-budget errors still fail immediately. Prompts explicitly require empty arguments. No tool permissions or run/iteration budgets were expanded.

- 2026-11-06 (migration Phase 0): Approved target is two development containers (React/Vite and FastAPI with reload) with SQLite on a persistent named volume and external Strata/providers unchanged. Refactor incrementally to feature-owned modules only after Docker acceptance. Git branch provides source rollback; private sibling backups protect ignored configuration/databases. Existing API/schema/financial and agent behavior stay fixed.

- 2026-11-06 (migration Phase 1): Use source bind mounts with Uvicorn reload/Vite HMR, digest-pinned Python 3.13.11/Node 22.23.3 images and two loopback-published services. Preserve native Vite fallback; allow only the exact additional `backend` host for the proxy. Use a named SQLite volume, separate fixture project/env override and exclusive, fingerprint-verified SQLite imports. Preserve diagnostic research as a separate DB, without silently merging it into the originally empty native default. External Strata discovery currently fails from both WSL and Docker; stop at the Phase 1 live-connectivity gate, retain validation and endpoints unchanged.
